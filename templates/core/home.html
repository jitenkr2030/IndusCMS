Platform

Reusable infrastructure for business applications.

Instead of rebuilding the same backend for every industry, IndusCMS provides reusable engines that can be assembled into different applications.

Business Engine Businesses, memberships, roles and permissions.
Entity Engine Configurable entities, fields and records.
Relationship Engine Connect dynamic business records.
Workflow Engine Steps, transitions, conditions and instances.
Event Engine Record events and workflow triggers.
Action Engine Actions, webhooks, retries and execution history.
API Engine REST API foundation and integrations.
Plugin Engine Planned extension system for industry modules.

Current Capabilities

What is working today.

Workflow Triggers

Record-created, record-updated and record-deleted events can activate workflows.

Webhook Actions

Workflow actions can call external HTTP endpoints with timeout, validation and security controls.

Retry System

Failed actions can be retried with persistent retry counters and scheduled backoff.

Async Worker

Asynchronous actions can be queued and processed by a Django database-backed worker.

Execution History

Action execution status, result, error and retry information are persisted.

Audit Trail

Workflow operations and important automation events can be tracked through audit records.
